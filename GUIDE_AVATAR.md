# 🎨 Guide d'utilisation - Modification d'avatar

## Comment modifier ton avatar

### Étape 1 : Accéder à ton profil
1. Connecte-toi à ton compte
2. Clique sur ton nom ou ton avatar dans la navbar
3. Tu arrives sur ta page de profil

### Étape 2 : Modifier l'avatar
Tu as **DEUX façons** de modifier ton avatar :

#### Option A : Cliquer sur l'avatar
- Clique directement sur ton avatar (rond en haut à gauche)
- Le modal de personnalisation s'ouvre

#### Option B : Cliquer sur le bouton
- Clique sur le bouton **"🎨 Modifier l'avatar"** sous l'avatar
- Le modal de personnalisation s'ouvre

### Étape 3 : Choisir ton nouvel avatar

Tu as **2 options** dans le modal :

#### 🎲 Option 1 : Génération aléatoire (rapide)
1. Clique sur **"🎲 Générer un avatar aléatoire"**
2. Un avatar est créé automatiquement parmi les 10 styles
3. Ton profil est mis à jour instantanément
4. Le modal se ferme

#### 🎨 Option 2 : Choisir un style spécifique
1. Parcours les **10 styles d'avatars disponibles** :
   - 👤 Avataaars (style cartoon humain)
   - 🤖 Bottts (robots)
   - 👥 Personas (personnages)
   - 🎮 Pixel-art (rétro gaming)
   - 🏃 Adventurer (aventurier)
   - 🐰 Big-ears (grandes oreilles)
   - 😄 Fun-emoji (emojis amusants)
   - 👩 Lorelei (féminin)
   - 🧑 Micah (moderne)
   - 🎭 Miniavs (mini avatars)

2. Clique sur le style que tu préfères
3. Un aperçu avec une variation aléatoire du style s'affiche
4. Tu peux cliquer sur un autre style pour voir d'autres variations
5. Quand tu es satisfait, clique sur **"✓ Valider ce style"**
6. Ton profil est mis à jour
7. Le modal se ferme

### Fonctionnalités

✅ **10 styles différents** d'avatars
✅ **Génération aléatoire** en 1 clic
✅ **Aperçu en temps réel** avant validation
✅ **Personnalisation infinie** (chaque style a des millions de variations)
✅ **Mise à jour instantanée** du profil
✅ **Aucun upload de fichier** nécessaire

### Problèmes courants

**Q : Je ne vois pas le bouton "Modifier l'avatar"**
R : Assure-toi d'être sur TON propre profil (pas celui d'un autre utilisateur)

**Q : Le modal ne s'ouvre pas**
R : Vérifie la console du navigateur (F12) pour voir les erreurs éventuelles

**Q : L'avatar ne se met pas à jour**
R : Vérifie que tu es bien connecté et que le backend est accessible

**Q : Je veux revenir à mon ancien avatar**
R : Tu peux régénérer ou choisir un autre style autant de fois que tu veux

### Informations techniques

- **API utilisée** : DiceBear API v7.x
- **Hébergement** : Avatars hébergés sur les serveurs DiceBear (CDN gratuit)
- **Format** : SVG (vectoriel, qualité parfaite à toute taille)
- **Taille** : Légers (quelques Ko par avatar)
- **Compatibilité** : Tous navigateurs modernes
